## Идентификация сети

- **Mainnet:**
  - Genesis-хэш:
    `edc7144fe1ba4edd0edf35d7eea90f6cb1dba42314aa85da8207e97c5339c801`,
    время генезиса 1655812800 (**21.06.2022**), nonce `03001700`
    (источник: `src/chainparams.cpp` gitlab.com/nexa/nexa)
  - Magic bytes: `0x72271221`
  - Порты: RPC `7227`, P2P **`7228`** (`NEXA_PORT`, `src/chainparamsbase.h`)
  - Блок: ~**2 минуты**; PoW sha256d-производная с Tailstorm-архитектурой
    (k=120: блоки-«summary» каждые ~2 мин, ~40 сабблоков между ними по ~3 сек
    в целевой конфигурации)
  - Сложность: ASERT, halflife 2 дня
  - Награда: старт 10,000,000 NEXA; халвинг каждые **1,050,000 блоков (~4
    года)**. **Первый халвинг состоялся 1 мая 2026** (блок 1,050,001,
    01:36 UTC): 10,000,000 → **5,000,000 NEXA (текущая)**; пройден рубеж 50%
  эмиссии. Следующий халвинг — блок 2,100,000 (~2030).
  - Эмиссия: максимум **21 трлн NEXA**; выпущено ~11.16 трлн на 31.10.2026.
    Дробность: **2 десятичных знака** в UX (сырые единицы — «nexa-сатоши»,
    их общее количество равно биткоиновскому 2.1 квадриллиона).
- **Testnet:** magic `0x72271222`, RPC `7229`, P2P `7230` (NEXA_TESTNET_PORT),
  genesis `508c843a...`; кран testnet-faucet.nexa.org.
- **Прочие сети:** stormtest (dev-цепь; RPC 7231, P2P 7232), scalenet, regtest
  (RPC 18332).
- **Проверка идентичности:** тикер однозначен. Nexa — UTXO-чейн Bitcoin
  Unlimited (запуск mainnet 21.06.2022; 4-летие отмечено в июне 2026);
  SLIP-44 coin type 29223; биржи (MEXC и др.) листингуют NEXA этой сети;
  genesis/magic/порты из официальных исходников. Двусмысленности нет.

## Криптография и ключи

- **Формат адреса:** два стандарта:
  - **Cashaddr (основной):** base32, префикс `nexa` → `nexa:...`. Версионный
    байт 152 = P2ST (script template) → адреса с `n...` (по spec.nexa.org);
    версионный байт 0 — легаси-P2PKH → `q...`. Префиксы сетей: `nexa`
    (mainnet), `nexatest` (testnet), `nexareg` (regtest).
  - **Base58 legacy:** P2PKH байт `25` → адреса `B...`; P2SH байт `68` →
    `U...`; script template байт `8`.
- **Формат публичного ключа:** SEC1 secp256k1.
- **Формат приватного ключа:** WIF, байт `35` (адреса начинаются `2B`/`2C`);
  расширенные ключи НЕ Bitcoin: xpub-аналог `0x42696720` («Big »),
  xprv-аналог `0x426c6b73` («Blks») — **нельзя** смешивать с BTC-стандартами.
- **Схема деривации ключей:** BIP32/BIP44; SLIP-44 coin type **29223**
  (зарегистрирован). Ожидаемый стандартный путь `m/44'/29223'/a'/c/i`;
  точная деривация официальных кошельков (Wally Wallet, Otoplo) при
  исследовании напрямую не вскрыта — **сверить с libnexa-kotlin при
  интеграции** (маркировка: ожидаём SLIP-44, `НЕ ПОДТВЕРЖДЕНО`, что Wally
  использует именно этот путь).
- **Мнемонический стандарт:** BIP39 (Wally Wallet: создание/восстановление
  по секретной фразе — официальный FAQ).
- **Алгоритм подписи:** **Schnorr (secp256k1)** — подписи транзакций по
  спецификации Nexa (spec.nexa.org); ECDSA-совместимость на уровне скриптов —
  по спецификации.
- **Совместимость восстановления из фразы:** фраза BIP39 + coin type 29223;
  из-за нестандартных расширенных ключей («Big»/«Blks») импорт xprv-строк
  из других сетей невозможен (защита от кросс-чейн путаницы).

## Транзакции

- **Структура транзакции:** UTXO Bitcoin-подобная, но с отличиями BCH-линии:
  sighash FORKID, script templates (P2ST), новые опкоды (SCRIPT_FORK1_OPCODES,
  UPGRade2), ограничение sigchecks вместо sigops (BLOCK_SIGCHECKS_RATIO 141).
- **Ограничения:** MIN_TX_SIZE 65 байт; максимум 256 входов и 256 выходов
  (`consensus.h`).
- **Размер блока:** адаптивный: базово 100 KB, после fork1 (высота 766,083,
  **31.03.2025**) — 2 MB с адаптацией по 90-дневному/365-дневному окнам
  (мультипликатор 10); максимум на горизонте — 1 GB (параметры long-term).
- **Расчёт комиссии:** sats/байт (нет gas); fee-rate из мемпула
  (mempool.get_fee_histogram в Rostrum/`estimatesmartfee` в RPC).
- **Блокировки/имматурность:** **COINBASE_MATURITY = 5000 блоков mainnet**
  (~7 дней при 2-мин блоках; `consensus.h`: mainnet 5000, testnet 100,
  stormtest 5). Независимое подтверждение: официальный FAQ Wally Wallet —
  «Nexa mining rewards take a week to mature». Для получателя выплат
  некритично (тратит пул), но критично отображать выплату как зрелую
  (immature → mature) в UI.
- **Модель баланса:** UTXO (+ нативные токены).
- **Особые поля:** отсутствуют (payment ID нет); group/token-выходы — вне
  начального scope.

## Доступ к сети

- **Методы RPC:** Bitcoin-подобный набор + Nexa-специфика; RPC-порт `7227`.
  Библиотеки-обёртки: NexaRpcKotlin.
- **P2P-протокол:** порт `7228`, wire-протокол BCH-производной (Bitcoin
  Unlimited; magic `0x72271221`), Tailstorm-сообщения (subblocks).
- **Лёгкий клиент:** **есть — Rostrum** (gitlab.com/nexa/rostrum): официальный
  Electrum-сервер на **Rust**, Electrum-протокол v1.4.3, TCP + WebSocket;
  актуальный релиз **14.0.0** (апрель 2026). Это основной честный путь
  лёгкого доступа для VEYRO (баланс/история/бродкаст/подписки — как в
  Electrum). Плюс electrum-cash JS-клиент для интеграции с Rostrum.
- **Узел:** Nexa Full Node (gitlab.com/nexa/nexa, Bitcoin Unlimited; C++).
  Актуальная версия 2.2.0.0 (02.09.2026) — включает код Tailstorm
  (неактивен до хард-форка #2; дата активации на 31.10.2026 не объявлена).
  Диск: полная цепь — `НЕ ПОДТВЕРЖДЕНО` точно (BCH-масштаб, десятки ГБ).
- **Публичные RPC:** официальные публичные серверы Rostrum существуют
  (используются Wally/Otoplo; конкретные хосты зафиксировать при интеграции
  из конфигурации официальных кошельков). Приватность: Electrum-сервер видит
  запрашиваемые адреса — шифрование, распределение запросов, поддержка
  пользовательских серверов обязательны.
- **Explorer:** официальный Nexa Explorer (block explorer с HODL Vaults,
  обновление июнь 2026); точный URL `НЕ ПОДТВЕРЖДЁН` в паспорте — сверить на
  nexa.org при интеграции. Существуют mainnet и testnet эксплореры.

## SDK и библиотеки

- **Официальные SDK** (build.nexa.org, активны на ноябрь 2026):
  - **libnexa** — C/C++ shared library из состава полного узла
    (`src/libnexa`): хэши, конвертация адресов, подпись транзакций, script
    evaluation — базовый движок для лёгких кошельков (FFI-кандидат для
    Rust-ядра VEYRO)
  - **libnexa-kotlin** — мультиплатформенная библиотека (Android, iOS, JVM,
    десктоп): ключи, адреса, построение транзакций, сеть (используется Wally
    Wallet)
  - **libnexa-ts 3.1.0** (октябрь 2026, read-only inputs) — TypeScript SDK;
    wallet-sdk-ts поверх libnexa-ts (кошелёк, токены, dApp-коннект)
  - NexaRpcKotlin, nexa-mcp (ноябрь 2026), explorer, seeder
- **Rust-библиотеки:** крейт `nexa` 24.4.15 (avasdao/nexars, MIT, апрель 2024)
  — **пустой toolkit (15 SLoC, 2 версии), НЕ годен**. Практический путь:
  (а) FFI к официальной libnexa (C/C++), (б) собственная реализация на
  BCH-совместимом Rust-стеке + Schnorr + cashaddr. Rostrum (Rust) — референс
  валидной реализации парсера/индексера.
- **Flutter/Dart-интеграции:** готового пакета нет; путь — FFI к Rust-ядру
  VEYRO (libnexa или собственный модуль).
- **Лицензии зависимостей:** узел Nexa/libnexa — MIT (Copyright Bitcoin
  Unlimited); libnexa-js/ts — MIT; rust-bitcoin (если используется для
  базовых структур) — MIT OR Apache-2.0. Совместимо с ядром VEYRO.

## Безопасность и ограничения

- **Хард-форк #2 (Tailstorm) на горизонте:** код Tailstorm уже в Full Node
  2.2.0.0 (сентябрь 2026), активация по хард-форку, дата на 31.10.2026 не
  объявлена. Fork1 (31.03.2025, высота 766,083) прошёл. При активации
  Tailstorm изменится P2P/структура блоков (сабблоки) — VEYRO должен
  отслеживать анонс и адаптировать SPV/RPC-слой.
- **Долгая coinbase maturity (5000 блоков ≈ 7 суток)** — уникально много для
  UTXO-чейна: UI обязан различать immature-выплаты.
- **Schnorr-подписи и нестандартные расширенные ключи** — нельзя переиспользовь
  BTC-модуль подписи напрямую; нужен тестовый контур с векторами из spec.
- **Экономический риск:** цена NEXA на историческом минимуме (~-99% от ATH,
  июль 2026); майнинг-доходность низкая, но сеть жива и активно развивается
  (релизы октября 2026: Otoplo 5.3.0, libnexa-ts 3.1.0).
- **Инцидентов консенсуса** (взломы/эксплойты) в 2025–2026 не зафиксировано;
  апгрейды проходят плановыми хард-форками.
- **Блокеры:** нет. Полный цикл реализуем без серверов VEYRO (Rostrum —
  open-source, можно рекомендовать пользователям собственный инстанс).

## Вывод для матрицы

- **Идентичность:** подтверждена (официальный GitLab Bitcoin Unlimited,
  SLIP-44 29223, genesis/magic/порты из исходников; два независимых
  источника ключевых параметров — код узла и spec.nexa.org).
- **Реализуемость:** полная — Rostrum (Rust, Electrum v1.4.3) + libnexa
  (FFI) покрывают весь цикл; Wally/Otoplo — референсы production-кошельков.
- **Главный риск:** предстоящий хард-форк Tailstorm (архитектура блоков
  изменится) + Schnorr/нестандартные ключи требуют собственной
  реализации, отличной от BTC-модуля VEYRO.
- **Предлагаемый статус:** `Research required` → после тестового цикла кандидат
  на `Full support`, но реализация дороже RVN/XNA/DGB (не переиспользуется
  BTC-модуль подписи). До тестов статус не менять.
