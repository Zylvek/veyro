## Идентификация сети

- **Mainnet:** не найден. Никакой PoW/PoS-сети с тикером XTR, доступной для майнинга или имеющей пулы, эксплореры, кошельки или биржевые рынки в 2025–2026 гг., не обнаружено.
- **Testnet:** не найден.
- **Проверка идентичности (отрицательные результаты, все выполнены 11.11.2026):
  - **CoinGecko:** поиск по тикеру XTR отсутствует (реестр ~22 600 монет; Quantus — symbol `qtc`, Pearl — `pearl`, Minotari — `xtm`; XTR нет).
  - **CoinPaprika:** живых активов с тикером XTR нет; есть только мёртвые исторические монеты **XatteR (XTR)** и **Xtremcoin (XTR)**.
  - **WhatToMine:** в полном списке калькуляторов XTR отсутствует (сохранённый полный вывод проверен; PRL/QTC/XTM присутствуют).
  - **minerstat:** XTR отсутствует.
  - **SafeTrade:** среди 278 рынков пары с XTR нет (при этом есть prl/pearl, quantus/qtc, xtm — т.е. три других исследуемых тикера биржа знает, XTR — нет).
  - **SLIP-0044:** записи XTR нет (там есть, например, `189189 | QUAN | Quantus Network`; для Tari/Pearl записей тоже нет).
  - **miningpoolstats.stream:** страницы /xtr нет (есть /pearl, /quantus, страницы tari по алгоритмам).
  - **Zergpool API** (api.zergpool.com/api/currencies, /api/status): 3 попытки — ECONNRESET из нашего окружения; **НЕ ПРОВЕРЕНО до конца** (косвенно XTR не встречается ни в одном майнинговом источнике).
  - **Веб-поиск:** «XTR coin mining» — только нерелевантное (см. гипотезу 5).
- **Гипотезы (в порядке правдоподобия):**
  1. **Ошибочная запись/дубликат XTM (Tari).** В майнинговом контексте, из которого взят список тикеров (пул Kryptex), Tari представлен тремя входами: XTM-SHA3X, XTM-RX, XTM-C29 («RX XTM» в UI пула). XTR мог возникнуть как искажение при сборе/скрейпе этих записей. Учитывая, что сам список монет pool.kryptex.com тикера XTR не содержит, а PRL/QTC/XTM в нём есть, XTR с высокой вероятностью — артефакт источника списка VEYRO, а не реальная монета.
  2. **Биржевая нотация L2-токена Tari (Ootle).** Биржа XT.com в своей статье «What is the Tari Token (XTR) and How it Works» (Medium, @XT.exchange) описывает Tari как «dual-token… combining Minotari (XTM) PoW security with **Tari (XTR)** layer-2 digital-asset programmability». То есть XTR — стороннее (XT.com) обозначение **L2-токена Tari**, который сам проект называет **TARI** (mainnet Ootle запущен 11.11.2026; создаётся только сжиганием XTM 1:1; Turbine Model, RFC O-0320). Курьёзная перекличка: в кодовой базе tari-ootle встречаются исторические константы `XTR_FAUCET_*` и шаблон `XtrFaucet` («сохраняют историческое написание»). Это **не майнящаяся монета** и **не тикер L1**; для майнинговой матрицы не подходит.
  3. **Xtreme Token (XTR)** — BEP20-токен на BNB Smart Chain (запуск 2021, supply 2 000 000 000), неактивен; не майнинговый, в пулах/калькуляторах отсутствует.
  4. **Мёртвые монеты:** XatteR (XTR) и Xtremcoin (XTR) — исторические (CoinPaprika, без активности); в майнинговом контексте 2025–2026 не участвуют.
  5. **Некриптовалютные тикеры XTR:** ETF Global X S&P 500 Tail Risk (биржевой тикер XTR), Xtract Resources plc (LSE: XTR), обозначение IEX XTR — нерелевантны.

## Безопасность и ограничения

- **Известные ограничения:** тикер XTR не идентифицирован — любая «поддержка XTR» в кошельке/матрице будет поддержкой несуществующего актива.
- **Риски безопасности:** главный риск — **добавить в продукт несуществующую монету**: пользователи не смогут получить/вывести средства, а интерфейс будет вводить в заблуждение. Дополнительный риск — путаница вокруг Tari: L1 тикер XTM, L2 тикер TARI, биржевая нотация L2 — XTR (XT.com); несогласованные обозначения почти гарантированно приведут к ошибкам выбора актива пользователями и поддержкой.
- **Блокеры:** сама идентичность тикера. До выяснения происхождения XTR в списке поддержка невозможна.

## Вывод для матрицы поддержки

**Идентичность тикера XTR не установлена — отдельной монеты не существует.** Рекомендуемый статус матрицы: **«Не добавлять / Blocked (дубликат или ошибка записи)»**:
- если источник списка — майнинговые пулы (Kryptex и аналоги), считать XTR **дубликатом/искажением XTM (Tari/Minotari)** и отображать как синоним XTM с пометкой «проверьте источник»;
- если требовался токен L2 Tari — использовать официальный тикер **TARI** (не XTR) и учитывать, что он не майнится и создаётся только сжиганием XTM 1:1;
- в любом случае — запросить у владельца исходного списка подтверждение происхождения тикера XTR.

Главный риск: внесение в матрицу выдуманного/несуществующего актива либо путаница XTM/TARI/XTR в интерфейсах.
