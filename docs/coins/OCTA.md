> Паспорт составлен по состоянию на 11 ноября 2026. Chain ID, генезис, газ и

> неизвестная сеть» снята: идентичность установлена (OctaSpace).

## Идентификация сети

- **Mainnet:**
  - Chain ID **800001** (`0xc3501`) — проверено напрямую RPC `eth_chainId`
    на официальном эндпоинте `https://rpc.octa.space`; подтверждено
    официальными доками (docs.octa.space/wallets: chain ID 800001, тот же
    RPC, эксплорер scan.octa.space). `net_version` = 800001 (проверено RPC).
  - Genesis-хэш:
    `0x4328489cccd9b8a33d4c5a63e813d883863e1ae1389a945b28b49d650f9227e9`
    (получен RPC `eth_getBlockByNumber("0x0")`); метка времени генезиса —
    2022-06-01; extraData `0x4f4354415350414345494e4954` («OCTASPACEINIT») —
    прямой маркер сети OctaSpace.
  - Consensus: PoW **Ethash** (майнинг GPU/ASIC на обычные `0x`-адреса;
    подтверждено сервисами майнинга WhatToMine и Kryptex).
  - Награда: **1,00 OCTA/блок**, блок ~12,6–13 с (WhatToMine + Kryptex,
    согласуются). Хешрейт сети ~1,25–1,9 Th/s (WhatToMine, ноябрь 2026).
  - Сеть жива: ~10,73 млн блоков (RPC); цена ≈ $0,0697, капитализация ≈
    $3,1 млн, ~1 287 транзакций/день (Blockscout API scan.octa.space,
    2026-11-11).
- **Testnet:** `НЕ ПОДТВЕРЖДЁН` — в официальных доках не упоминается.
- **Проверка идентичности:** тикер OCTA однозначен — это собственный L1
  проекта OctaSpace (не форк Ethereum и не токен сторонней сети):
  подтверждено официальными доками (chain ID 800001 + rpc.octa.space +
  scan.octa.space), официальным репозиторием узла (extraData генезиса
  «OCTASPACEINIT», получено RPC), bitcointalk-анонсом и листингом на
  биржах/пулах. Двусмысленности нет.

## Криптография и ключи

- **Формат адреса:** `0x`-hex, 20 байт, чексумма EIP-55 (стандарт EVM).
- **Формат публичного ключа:** secp256k1 (как Ethereum).
- **Формат приватного ключа:** 32 байта; hex `0x…` / keystore Ethereum.
- **Схема деривации ключей:** практика — `m/44'/60'/a'/0/i` (ETH-путь).
  **Регистрации в SLIP-44 нет.** Практика подтверждается официальной
  конфигурацией MetaMask (docs.octa.space/wallets) и поддержкой аппаратных
  кошельков: Tangem, Trezor, Ledger (через MetaMask/приложение Ethereum),
  OneKey.
- **Мнемонический стандарт:** BIP39.
- **Алгоритм подписи:** ECDSA secp256k1, EIP-155 (chainId 800001).
- **Совместимость восстановления из фразы:** идентична Ethereum (тот же
  путь 60') — адреса совпадают с ETH-кошельками той же фразы; UI обязан явно
  идентифицировать сеть.

## Транзакции

- **Структура:** стандартные EVM legacy-транзакции (type 0). EIP-1559 не
  активен: `eth_feeHistory` возвращает baseFee = 0 (проверено RPC);
  отправлять legacy-транзакции с `gasPrice`.
- **Расчёт комиссии:** gas × gasPrice; `eth_gasPrice` ≈ 1 gwei (проверено
  RPC), `eth_estimateGas`.
- **Блокировки/имматурность:** аккаунтная модель; coinbase-имматурности для
  получателей нет; PoW-реорги возможны — подтверждать переводы блоками.
- **Модель баланса:** account/nonce.
- **Особые поля:** нет.

## Доступ к сети

- **Методы RPC:** стандартный EVM-набор (см. паспорт ETC); проверены
  напрямую 2026-11-11: eth_chainId, net_version, eth_getBlockByNumber
  (генезис/высота), eth_feeHistory, eth_gasPrice, eth_getLogs.
  **Ограничение:** `eth_getLogs` на rpc.octa.space принимает диапазон не
  более **2 000 блоков** (проверено: RPC отклоняет больший диапазон) —
  историю собирать окнами.
- **P2P-протокол:** devp2p (стек go-ethereum); порт узла 38000 (из
  исходников go-octa).
- **Лёгкий клиент:** нет.
- **Узел:** единственный клиент — `octaspace/go-octa` (форк go-ethereum
  **v1.10.17**; лицензии LGPL-3.0/GPL-3.0). Последний коммит — 04.11.2024,
  последний релиз v2.0.0: **заморожен ~2 года**, апстрим-фиксы безопасности
  geth не портируются.
- **Публичные RPC:** официальный — `https://rpc.octa.space` (жив, проверен).
  Другие публичные эндпоинты НЕ ПОДТВЕРЖДЕНЫ. Единая точка отказа и
  приватности; допускать пользовательские эндпоинты.
- **Explorer:** https://scan.octa.space (Blockscout; REST API v2 работает —
  проверено) и https://explorer.octa.space (живость НЕ ПРОВЕРЯЛАСЬ).

## SDK и библиотеки

- **Официальные SDK:** OCTA-специфичные не требуются — стандартный EVM-стек;
  официальные доки описывают подключение MetaMask (стандартные EVM-методы).
- **Rust-библиотеки:** `alloy`/`ethers-rs`, `k256` — MIT OR Apache-2.0.
- **Flutter/Dart-интеграции:** те же, что для ETC (см. паспорт ETC).
- **Лицензии зависимостей:** узловое ПО go-octa (LGPL/GPL) в кошелёк не
  включается; кошелечный стек — MIT OR Apache-2.0. Совместимо.

## Безопасность и ограничения

- **Микрокапитализация** (≈ $3,1 млн): повышенный риск экономических атак,
  делистингов и резкой волатильности; поддержка экспериментальная по
  определению.
- **Замороженный узел-клиент** (последний коммит ноябрь 2024, база — geth
  v1.10.17): известные уязвимости geth не закрыты; риск деградации сети.
- **Единый публичный RPC** (rpc.octa.space) — единая точка отказа и
  приватности.
- **Лимит getLogs** (2 000 блоков) — история собирается окнами; для новых
  адресов полная история требует долгой выкачки (или Blockscout API).
- **Отсутствие тестнета** (НЕ ПОДТВЕРЖДЁН) — e2e-тестирование только на
  mainnet или локальной dev-сети.
- **Блокеры:** технических нет; перечисленное — операционные оговорки.

## Вывод для матрицы

- **Идентичность:** подтверждена (RPC chainId/генезис + официальные доки
  OctaSpace; extraData генезиса «OCTASPACEINIT»; ≥ 2 источника).
- **Реализуемость:** полная технически (стандартный EVM-цикл, legacy-газ);
  доработки минимальны, главный нюанс — история окнами ≤ 2 000 блоков.
- **Главный риск:** хрупкость экосистемы — микрокап, замороженный с 2024 г.
  узел, единственный RPC, лимиты getLogs.
- **Предлагаемый статус:** `Research required` → после тестового цикла
  кандидат на `Full support` с оговорками (низкий приоритет относительно
  ETC; учитывать риск исчезновения сети).
