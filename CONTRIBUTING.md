# Contributing

Спасибо за интерес к VEYRO. Проект — **некастодиальный кошелёк**, лицензия
**AGPL-3.0-only** (см. [LICENSE](LICENSE)), и правила ниже — не бюрократия,
а рамки, внутри которых код принимается.

Любой PR засчитывается как согласие с лицензированием вклада под
**AGPL-3.0-only**: модификации не могут быть выпущены под другой лицензией.

## Жёсткие рамки продукта

Не принимаются изменения, добавляющие:

- обмены, свапы, DEX/CEX-интеграции, стейкинг, DeFi, кредитование, NFT;
- майнинг-функциональность в UI;
- кастодиальные механизмы, регистраций, облачные «синхронизации»;
- бэкапы экспортов — восстановление **только** seed-фразой 12/24;
- watch-only и адресную книгу;
- ручной выбор серверов/узлов (списки принадлежат ядру);
- рекламу в любой форме;
- НЕ-TLS соединения (`tcp://`); P2P — только с проверкой magic/genesis.

## Правила честности

1. **researched ≠ implemented.** Статус монеты в матрице меняется только
   после полного живого тест-цикла (свидетельства — в паспортах `docs/coins/`).
2. Данные, которых нет у ядра, не выдумываются: нулевой баланс ≠ «не
   синхронизировано»; история без данных — «пусто», не 0.
3. Секреты никогда не пересекают FFI; валидация входа — в ядре.

## Технический гейт перед PR

```powershell
cd rust
cargo fmt --check
cargo clippy --all-targets
cargo test
cargo audit

cd ..\apps\veyro
dart analyze
flutter test          # все виджет-тесты зелёные
flutter build windows --release
```

- Новые строки UI — только через l10n-словарь (RU + EN).
- Патчи — по существу, без переформатирования соседнего кода.
- PR описывает: что, зачем, чем проверено (гейты + живая проба для протокола).
